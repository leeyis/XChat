日期：2026-10-10。基线：`5feb647`。状态：原型已完成，等待用户评审新增交互。

## 交互约定

| 操作 | 结果 |
| --- | --- |
| 拖动左侧六点手柄 | 面板在远程画面范围内移动，鼠标和触摸使用同一交互 |
| 点击隐藏 | 完整面板收成小浮标，继续显示共享 / 控制 / 暂停状态 |
| 点击浮标主体 | 完整面板恢复到隐藏前的位置 |
| 拖动浮标手柄 | 独立调整浮标位置，不覆盖完整面板位置 |
| 浮标上的结束按钮 | 立即结束协助；共享方被控制时另保留收回控制按钮 |
| 缩小窗口 / 展开远程桌面 | 将当前面板约束到可见范围，避免恢复入口丢失 |
| 手柄聚焦后按方向键 | 每次移动 8px，Shift + 方向键移动 24px；Home 复位 |

隐藏不修改屏幕共享、控制权限或双向语音。暂停、撤权等状态变化后浮标文案同步更新。双方的位置与折叠状态分别保存于当前会话，重新发起会话默认展开。关闭、断线或离开远程视图时移除拖动监听和尺寸观察器。

共享方将“状态、收回控制、暂停、结束”作为浮动控制栏；主页面的屏幕与画质选项保留原位置。协助方的显示比例、画质、全屏、申请 / 释放控制和沟通工具整体浮动。
