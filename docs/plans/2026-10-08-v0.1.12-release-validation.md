# 0.1.12 发布验证

用户明确授权升级小版本、提交代码、同步远程仓库，最后编译安装包。沿用仓库的补丁版本约定，从 0.1.11 升至 0.1.12，Windows x64 产物为 NSIS EXE 和 MSI。

## 发布内容

- 直接框选、原位贴图与保持位置和缩放的标注流程。
- 独立并预加载的贴图菜单，修复右键闪动、窗口偏移与底部透明增高。
- 去掉菜单绿色焦点边框及所属分组，显示穿透与恢复快捷键。
- F3 恢复隐藏或穿透贴图；重新打开主窗口也可解除鼠标穿透。
- npm、Cargo、Tauri、前端兜底、Android 版本名兜底、中英文 README 和版本一致性测试同步为 0.1.12；保留 Android 工程结构。

UI 已按用户批准的原型实现。本轮完整 Windows 交互验收及坐标、延迟证据见[贴图稳定性验证](2026-10-08-capture-pin-stability-validation.md)。

提交前复核补齐了 `lib.rs` 中新增贴图命令的桌面平台条件编译标记，与对应命令定义一致，避免移动端注册桌面专用接口。

## 提交与构建

目标仓库为 `https://github.com/leeyis/XChat.git`，分支 `main`。远程通信沿用单次命令参数 `http.sslBackend=schannel` 和 `http.version=HTTP/1.1`，证书验证保持开启。

按照用户指定顺序，提交并推送后再执行 `rtk cargo tauri build --bundles nsis,msi`。使用正常应用标识 `com.xchat.app` 和已有 `tauri.windows.conf.json`，保留相对 frontendDist；不使用 QA 配置，也不创建会触发其他平台构建的版本标签。

构建完成后在本记录补充源码提交、安装包版本、SHA256 和包内资源核验结果。

## 验证范围

混合 DPI 多显示器、macOS、Linux 和移动端未做硬件烟测。F3 恢复的原生处理器已验证；本轮未注入物理全局 F3 按键。安装包构建与载荷核验不会覆盖安装用户现有实例。
