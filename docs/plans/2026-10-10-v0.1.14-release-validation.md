# 0.1.14 发布验证

用户明确授权：本轮问题修复后升级小版本、提交并推送远程仓库，最后编译 Windows 安装包供手工测试；随后确认一并包含此前完成的开机自启动和建群在线状态。沿用补丁版本约定，0.1.13 升为 0.1.14。

## 发布内容与范围

- 按已批准的 remote-v3 原型实现独立远程窗口、聊天分离、全屏与主机信息，以及无额外外框的共享工具条；被控方不再显示递归预览。
- Windows DXGI、GPU NV12、硬件 HEVC、原生授权 WebSocket 和 DedicatedWorker 传输，保留兼容 RTP 回退。
- 修复控制通道重连中误停 HEVC、首帧获取失败后的 GDI 回退、过期会话/帧清理和语音异步生命周期。
- 桌面开机自启动设置、真实系统状态确认，建群在线优先与在线/离线状态展示。
- 同步 npm、Cargo、Tauri、前端显示兜底、Android 版本名兜底与中英文 README；不重生成 Android 工程。

## 发布前证据

- `rtk npm test`：299 项通过，0 失败，包括版本一致性与新控制通道恢复回归。
- `rtk npm run build`：通过，包含独立 Worker 资源。
- `rtk cargo check --manifest-path src-tauri/Cargo.toml --no-default-features --features desktop --lib -j 2`：通过。
- `rtk cargo check --manifest-path src-tauri/Cargo.toml --no-default-features --features web --bin lanchat-web -j 2`：通过；保留三个原生专用捕获辅助项的 dead-code 警告。
- `rtk git diff --check`：通过。
- 原生应用通过 8 项真实 Windows/WebRTC 流程：无自预览、独立查看窗口、帧传输、模拟麦克风通话、输入通道恢复、暂停恢复、原生全屏，以及关闭远程窗口保留主聊天。
- 1080p RDP 前台 31.39 FPS、最小化 31.40 FPS；25 个有效源图像时间样本平均 164.68 ms、p95 203 ms。测试期间无 rustc 或 Codebase MCP；源窗口、接收端与 RDP 共享同一台机器，不能当作双机局域网验收。
- DXGI 与 NVIDIA HEVC Encoder MFT 已实际使用。macOS 实体麦克风、硬件解码及用户提出的 32 FPS / 约 60 ms 最低性能要求尚未完成验收。
- 自启动及建群功能此前已完成隔离原生验证，见[记录](../verification/2026-10-10-autostart-group-presence.md)。

详细远控证据及历史失败结果见[远控验证](../verification/2026-10-10-remote-followup.md)。原始桌面截图、临时会话地址、诊断二进制与构建缓存不进入源码提交。

## 提交与安装包

源码按自启动/建群、远控和版本资源分组提交，推送后执行 Windows Release 打包。沿用正常应用标识 `com.xchat.app` 与 `tauri.windows.conf.json`；不使用隔离 QA 配置，也不创建会触发 Android 构建的版本标签。

构建缓存盘 K: 空间不足，正式打包将使用 F: 上的本次专用 Cargo 目标目录，复用已有 release 缓存。编译限制为两个任务，编译时不运行 FPS 测量。Codebase MCP 保持关闭。
