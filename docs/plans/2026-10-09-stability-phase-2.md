## 验证契约

1. 资源测试覆盖多个并发世代/发送端；实际活跃流、摘要/合并不得突破明确上限，消息/ACK/取消不占文件许可。
2. 文件故障覆盖临时 5xx/繁忙、连接失败、重复块、响应丢失、永久错误、取消、内容变化；重试有次数和总时限，确认字节不重复累加。
3. 高频进度必须明显减少 SQL 次数；持久化终态不能被合并进度或过期 worker 覆盖。
4. 增量同步与全量校正结果等价；游标过期/重启/删除记录不能留下幽灵数据。
5. 大量无到期任务的离线联系人不产生逐联系人网络任务；正常目标不会被离线积压阻塞。
6. 使用替代端口、临时数据库与下载目录。保留阶段一 Web 162 / Desktop 187 + 2 ignored 的回归基线。检查 desktop/web，尽可能复验 Android arm64。
7. 同机 loopback 结果只证明本地回归和资源边界；1 GiB/4 GiB、慢盘、Wi-Fi 和实机项目以实际执行记录为准，不伪称跨设备达标。
