# XChat 截图文本、钉图与桌面提醒补全设计

日期：2026-07-30

## 1. 背景

`26191b3` 分叉：

- `main` 已包含 `45d5f7c`，修复了截图文本首次输入和 Finder 文件拖放；

## 2. 目标

1. 完整合入 `9c27425` 的全部功能，不删除通知、托盘提醒或主机上线提醒。
2. 保留 `45d5f7c` 的截图文本首次输入和 Finder 文件拖放修复。

   - 点击已有文本原位编辑；

4. 恢复钉图滚轮缩放、右键菜单、工具条和原生窗口控制。
5. 设置页选中项不再显示粉红色或强调色背景。

## 3. 非目标

- 不为矩形、椭圆、箭头、画笔或马赛克增加二次编辑和移动。
- 不改为多钉图窗口；继续保持单例钉图。
- 不新增截图或通知依赖。
- 不修改现有消息、文件传输或 SQLite 序列化协议。

## 5. 截图文本交互

### 5.1 操作模型

文本操作具有稳定 ID：

```text
{ id, tool: "text", start: { x, y }, text, color, size }
```

截图历史保存当前操作列表以及 undo/redo 的列表快照。新建、编辑和移动都通过同一
历史入口提交，因此每次用户动作只生成一个撤销步骤。截图操作数量很小，快照数组
比增量命令日志更直接，也避免编辑旧操作后撤销错误地删除其他标注。

### 5.2 命中与编辑

- 只有文本工具激活时才命中已有文本，避免使用其他工具时误操作。
- 使用与 Canvas 绘制一致的字体和 `measureText` 计算文本边界，从最上层文本向下
  命中。
- 单击已有文本后，Canvas 暂时不绘制该操作，在原位置显示输入框，保留原文字、
  颜色和字号，焦点位于文字末尾。
- Enter 或失焦提交修改；Escape 取消并恢复原内容。
- 编辑后为空视为取消，避免意外删除；本轮不新增文本删除交互。

### 5.3 移动

- 在已有文本上按下鼠标后进入点击/拖动判定状态。
- 移动超过 4 个 CSS 像素后转为拖动；未超过阈值则按单击编辑处理。
- 拖动时隐藏原位置文本并实时绘制移动预览。
- 文本边界限制在截图选区内；松开时提交一次位置更新。
- Escape 或 pointer cancel 恢复原位置，不写入历史。

### 5.4 新建与导出

- 文本工具激活时点击空白区域继续创建新输入框。
- 导出、保存、完成和钉图前提交当前有效输入。
- Canvas 预览与最终 PNG 使用同一份已解析操作列表，避免预览与输出不一致。

## 6. 钉图

钉图保持无边框、始终置顶、单例窗口。图片区域左键拖动窗口，菜单和控件不触发
窗口拖动。

### 6.1 缩放

- 滚轮向上放大 `×1.1`，向下缩小 `÷1.1`，比例按 1% 四舍五入。
- 缩放范围为 20%–300%。
- 初始和“适合窗口”比例为
  `min(100%, 960 / 原图宽度, 720 / 原图高度)`。
- 每次缩放由 Rust 按原图尺寸乘以比例调整 Tauri 原生窗口大小。

### 6.2 右键菜单

菜单依次包含：

1. 复制图像（当前显示比例）
2. 复制原始大小图像
3. 图像另存为 PNG
4. 原始大小（100%，显示 `⌘0`）
5. 适合窗口
6. 显示工具条（复选）
7. 窗口阴影（复选，同时修改 CSS 与原生窗口 shadow）
8. 关闭
9. 销毁（危险项）

菜单贴随鼠标并限制在窗口可视范围内，在执行动作、Escape、窗口失焦或尺寸变化后
关闭。复制、保存和失败操作显示短暂状态反馈。

### 6.3 工具条和生命周期

- 可选工具条包含缩小、比例、放大、复制、保存和关闭。
- 点击比例恢复 100%。
- 工具条隐藏时，鼠标悬停显示右上角关闭按钮。
- “关闭”只隐藏窗口并保留钉图状态。
- “销毁”关闭窗口并清理钉图状态及临时文件。

## 7. 桌面提醒

完整保留 `9c27425` 的提醒行为：

- 收到非本人、非协议控制类型的新文本或文件消息时生成提醒摘要。
- 应用不可见或未聚焦、且用户启用通知时，发送系统通知并启动托盘提醒。
- 对同一消息去重，缓存最多 256 个提醒键。
- 主窗口重新聚焦、可见或消息已读时停止托盘提醒。
- 新发现主机上线时显示应用内成功提示；允许通知时同时显示系统通知。
- macOS desktop capability 明确报告通知可用。

通知调用失败只影响提醒本身，不阻断消息接收、文件传输或设备发现。

## 8. 设置导航样式

删除 `.settings-nav-row.selected` 的背景声明。选中项继续使用强调色文字和较高字重；
悬停仍使用中性灰背景，`aria-current="location"` 和滚动同步逻辑保持不变。

## 9. 错误处理

- 钉图复制、保存、缩放、阴影和关闭命令失败时在钉图窗口显示错误，不关闭窗口。
- 无有效钉图时后端命令返回明确错误，不创建空文件或无效剪贴板内容。
- 文本编辑取消、空输入或 pointer cancel 不修改历史。
- 合并冲突必须保留双方已有测试覆盖的行为，不能通过删除测试解决。

## 10. 验收与验证

- 文本命中测试：重叠文本优先命中最上层，边界外不命中。
- 历史测试：文本新建、编辑、移动分别可撤销和重做。
- 移动测试：阈值判断、实时位置和选区边界限制。
- 钉图测试：适合窗口、20%–300% 缩放、菜单边界。
- 提醒测试：过滤控制消息、自发消息、重复消息并生成正确文件摘要。
- 设置样式检查：选中规则不存在背景声明。
