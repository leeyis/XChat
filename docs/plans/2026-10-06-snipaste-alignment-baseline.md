# XChat 截图与 Snipaste 对齐基线

状态：原型 v0.8 已批准：直接框选、原位贴图与标注，移除截图工作台；菜单显示穿透/恢复快捷键，移除绿色焦点边框和所属分组。创建：2026-10-06。更新：2026-10-08。基线版本：0.8。新增实现与验证见[贴图稳定性验收](2026-10-08-capture-pin-stability-validation.md)，历史基础能力范围及差距继续见原实施验收。

XChat 将现有截图功能扩展为可以独立使用的桌面截图与贴图工具，同时保留加入聊天草稿的出口。根据用户确认，本基线仅对齐 Snipaste 2.11.3 的基础功能，Pro 功能不属于交付或验收范围。第一优先级是选区、文字输入、再次编辑和移动，尤其是文字定位偏移与编辑不便。用户于 2026-10-07 明确回复“评审通过，开始全面实现吧，WEB端和PC端都要进行全面优化”，已授权以 v0.7 原型为基准进行生产实施。

## 2026-10-07 评审修订

本轮以用户反馈为准，替换第一版的文字操作规则。Snipaste 的基础能力范围保持不变，以下交互已随 v0.7 原型获得确认。生产覆盖、验证证据和仍未实现的基线能力见[双端实施验收](2026-10-07-capture-implementation-validation.md)，未通过的项目不计为完成。

| 反馈 | 本轮调整 |
| --- | --- |
| 不够精细、有设计感；工具条使用浅色 | 截图态采用紧凑的浅色浮动工具条，工具、历史和输出分组；属性栏合并到同一面板，采用浅灰绿底色与深色文字；选中态和“完成”沿用 XChat 绿色，笔触大小预览同步为浅色 |
| 图标精细度、风格与尺寸统一 | 工具条统一使用 24×24 SVG 坐标、20×20 CSS px 图标、1.75 单位描边与圆角端点；按钮为 30×30 px，窄窗口统一收为 28×28 px。重新绘制贴图、荧光笔、橡皮擦，并校正其他工具轮廓与撤销/重做镜像；普通态统一灰绿，选中态使用同一绿色，禁用态统一减淡 |
| 完成按钮过大 | 改为与其他工具等大的绿色对钩图标，移除文字与实心大底色；悬浮提示为“完成 · 复制截图”，保留可访问名称和复制并结束行为 |
| 不出现对标产品文字说明 | 界面场景入口、快捷键预设和评审说明仅使用 XChat 或中性名称；参考产品名称仅留在内部功能研究文档，不进入原型界面文案 |
| 贴图提示不要常驻 | 左下角的缩放、透明度与右键提示只在指针悬浮该贴图时显示；选中、键盘聚焦及穿透状态均不强制显示，鼠标移开即隐藏 |
| 贴图窗口阴影可关闭 | 右键菜单增加“窗口阴影”勾选项，默认开启，每张贴图独立保存；关闭时去掉阴影、边框、选中描边、聚焦描边及穿透虚线，仅显示图片本身 |
| 滚轮快速调粗细和大小 | 向上增大、向下减小；覆盖形状、线条、箭头、画笔、荧光笔、马赛克、模糊、橡皮擦和文字；数值、笔触预览和实际绘制同步 |
| 移除贴图右上角按钮 | 删除最小化和更多按钮，保留右键菜单；通过右键/Esc/双击收起时显示“恢复”，工作台也显示已收起数量 |
| 文字操作不自然 | Enter 换行；点击文字框外完成；删除独立移动、删除与完成操作条；边框悬浮为手形，可拖动；编辑焦点中 Delete 删除整条，Backspace 正常删字 |
| 截图被顶部工作台占位 | 截图时隐藏工作台顶部、底部、说明及设置按钮，画布从页面左上到右下铺满；Ctrl+A 选择完整画面，结束或取消后恢复工作台 |

“全屏”在本轮网页原型中指整个浏览器可视区。生产实现须覆盖目标显示器的真实捕获范围。原型底图、Canvas 和文字统一等比显示，窗口变窄时保持比例，避免原先横纵独立缩放造成的文字拉伸。

## 本次不做的功能

OCR、二维码识别、超级截图、层级控件检测、图形通用再编辑、编号、放大标注、虚线样式、透明白板、贴图裁剪与灰度反色、多图选择、虚拟桌面、热角和高级自动化不进入本轮原型与实施计划。此边界依据用户确认和[免费版与 Pro 对照](https://github.com/Snipaste/feedback/wiki/PRO)。

XChat 已经拥有的文字再次编辑和移动继续保留并修正，不能因为源产品将“再编辑”归入 Pro 而回退现有能力。

基础版文字旋转、角点缩放、贴图复位及最近关闭图恢复，分别以[基础操作](https://github.com/Snipaste/feedback/wiki/Getting-Started)为行为依据；图片格式与 GIF 控制见[官网功能说明](https://www.snipaste.com/)。本轮不把所有图形的旋转、任意大小缩略图或置顶开关算入基础版要求。

## 选区与文字的首要验收

这些用例优先于增加新工具。文字以原始截图中的左上角作为锚点，编辑框和 Canvas 使用相同的字体、字号、行高和字体基线。输入框边框、内边距、工具条和系统缩放均不得计入文字坐标。

| ID | 操作 | 预期结果 |
| --- | --- | --- |
| T01 | 在选区左上、中间、右下点击文字工具并输入 | 文字从点击位置开始；输入前后、提交后位置一致，边缘通过调整编辑框而不是改变文字锚点避让 |
| T02 | 单击已有文字 | 直接在原位置编辑，保留内容与样式；编辑时隐藏原绘制文字，避免叠字 |
| T03 | 输入中调整字号、颜色或字体 | 即时更新当前文字；光标与输入内容保留；工具参数交互不会提前结束文字编辑 |
| T04 | 按 Enter、Delete、Backspace、Esc，并使用中文输入法 | Enter/Shift+Enter 换行；点击文字框外完成；输入法候选确认不触发提交或删除；编辑焦点中 Delete 删除整条，Backspace 普通删字；Esc 取消本次修改 |
| T05 | 悬浮并拖动文字编辑框边框 | 出现手形，按下超过 4 个 CSS 像素才开始拖动；抓取点不跳到文字左上角；不再有独立移动图标；一次拖动产生一次撤销 |
| T06 | 改文字、移动、撤销、重做 | 每一步恢复正确的内容、样式和位置，不出现旧文字残影 |
| T07 | 移动和改变选区 | 截图像素与文字保留原图坐标，选区只改变裁剪范围；移动整张贴图时，文字随图整体移动 |
| T08 | 在 100%、125%、150%、200% 显示缩放下重复 T01 至 T07 | 客户区、图像像素与屏幕坐标只转换一次；交互预览不出现累计偏移；取整误差不超过 1 个输出像素 |
| T09 | 复制、保存、贴图和加入草稿 | 字体、换行、颜色和锚点与编辑预览一致；不带编辑边框与把手 |
| T10 | 多行长文字、选区边缘、窗口尺寸变化 | 编辑控件可见且能操作；底层锚点不因控件避让改变；再次编辑仍定位到原文字 |
| T11 | 文字未提交时点击外部或 Delete | 外部单击只完成当前编辑，不顺带创建空文本；Delete 后撤销恢复删除瞬间的文字，包括刚输入的内容 |
| T12 | 滚轮调整可调工具 | 当前值实时变化、遵守上下限；画布预览与下一次绘制使用相同大小；选区模式不响应画笔滚轮调节 |
| T13 | 开始截图、Ctrl+A、取消或输出 | 工作台栏全部隐藏；选区覆盖完整底图；取消或输出后恢复原工作台；导出没有任何工具条或编辑边框 |

原型提供“文字与选区检查”入口直接进入这些场景。100%、125%、150%、200% 模拟密度在截图前的工作台中选择，截图时这些控制隐藏。模拟密度用于检查坐标转换设计，不能代替真实操作系统缩放和多屏测试。

### 坐标与编辑约束

选区和文字锚点只存原图像素。指针进入编辑器时按画布实际显示矩形转换：x = (clientX − rect.left) × imageWidth / rect.width，y 同理。显示时使用这一个变换的逆变换；不能再叠加设备缩放或窗口偏移。文字移动使用按下时的锚点加指针增量，不能从经过避让的编辑框 CSS 位置反推锚点。

字体、字号、字重、行高与每行基线使用同一布局结果。切换字体或字号保留文本和插入点；只在一次提交时生成历史节点。输入框避让和工具条避让只影响控件位置。视图缩放采用相同的横纵比例，不修改源坐标；居中留白的偏移也进入指针换算。导出时统一取整并裁剪。原型密度按钮仅用于对照模拟数据，不能直接用作生产系统的 DPI 实现。

## 交互规则

### 截图流程

唤起后冻结桌面，先隐藏捕获层自身。状态依次为待选择、框选或识别、选区确认、标注、输出。工具条跟随选区，在屏幕边缘自动移到内部或上方，不截入最终图片。捕获过程中应隐藏哪些 XChat 窗口必须可配置；结束时恢复发起前窗口的可见状态和焦点，独立截图不强行弹出聊天窗口。

拖动产生自选区；悬停产生候选区，单击确认。选区确认后可移动或从八个控制点调整大小。已有标注时调整选区需保留标注在原图中的坐标与裁剪结果。文字输入中 Enter 换行，点击框外结束；属性栏调整不提前结束文字输入。折线的 Enter 只完成折线，不能同时复制截图。右键先完成当前图形；无草稿时返回选区选择，再次右键退出。Esc 先取消当前未提交编辑，再退出截图。

输出提供复制、保存、贴图和加入聊天草稿四个明确出口。工具条右侧绿色对钩代表“完成”，与其他图标使用相同按钮尺寸，点击后复制并结束；悬浮提示和可访问名称说明其用途。没有文字或折线正在输入时，Enter 也复制并结束。加入草稿不自动发送。复制失败、取消保存对话框和目标会话失效均保留当前编辑数据。保存、复制和贴图必须使用同一渲染结果，输出不包含边框、控制点、菜单和原型提示。

### 标注流程

底图、已提交标注和当前草稿分别保存。只在输出时合成。新建、编辑、移动、擦除各生成一个历史节点；鼠标移动不生成大量撤销记录。切换工具先提交有效文字；输入法组合输入不被 Enter 或快捷键打断。橡皮擦仅处理标注层；马赛克与模糊对导出图像真正生效。纯文本内容通过文本节点或 Canvas 渲染，不作为 HTML 执行。

滚轮向上增大、向下减小当前工具参数。形状、直线、折线、箭头和画笔范围 1–32 px，步长 1；荧光笔/橡皮擦 4–80 px，步长 2；马赛克颗粒 4–48 px，步长 2；模糊 2–32 px，步长 1；字号 10–96 px，步长 2。触控板小增量累积，避免每个微小事件都调整；不同画笔类型记忆本次会话内自己的大小。文字编辑中滚轮作用于字号，并保留内容、插入点和锚点。上述数值为 XChat 原型交互参数，属于本轮待评审设计，不宣称是 Snipaste 的数值。

### 贴图流程

每张图独立保存源图、标注、位置、缩放、旋转、翻转、透明度、窗口阴影、分组、隐藏及穿透状态。滚轮缩放，Ctrl 加滚轮调透明度；1/2 旋转，3/4 翻转。双击隐藏，Shift 加双击切换缩略图，空格进入或退出标注。右键菜单包含原图复制、当前显示结果复制、保存、变换、窗口阴影、穿透、分组、隐藏和销毁。

“窗口阴影”默认勾选；未保存该字段的旧贴图也按开启恢复。取消勾选后立即移除贴图容器的阴影、边框和所有状态描边，包含选中、键盘聚焦及穿透虚线；重新勾选恢复阴影。此设置按贴图保存，不影响其他贴图或新建贴图的默认值，不改变图片内容、位置、大小或导出结果。关闭阴影仍可拖动、缩放、右键操作，悬浮提示沿用仅悬浮显示规则。

隐藏保留记录，销毁移除记录。穿透后不能依赖点击当前窗口来关闭穿透，必须提供全局解除动作。分组切换不销毁图像；重启恢复时优先保持布局，屏外图片提供“找回”动作。

贴图表面不出现最小化或更多按钮。左下角的缩放、透明度与右键提示仅在鼠标悬浮当前贴图时显示，移开即隐藏，选中也不常驻。右键承担完整菜单操作；单图收起后提供可直接点击的“恢复”反馈，工作台入口显示收起数量，避免无从找回。收起与永久销毁保持不同语义。

## 平台约束与错误状态

| 平台 | 目标与边界 |
| --- | --- |
| Windows | 首轮系统验收平台；混合 DPI、窗口与控件识别、快捷键、剪贴板和穿透均须实测 |
| macOS | 同一编辑和贴图模型；屏幕录制、辅助功能权限、Retina 与 Spaces 单独验收 |
| Linux | X11 和 Wayland 分开记录；门户授权、桌面环境与窗口能力不能共用一张“支持”勾选表 |
| Web | 共享编辑器、导出和聊天草稿；系统抓屏须用户选择来源，不能宣称系统置顶或全局穿透。[屏幕捕获规范](https://www.w3.org/TR/screen-capture/) |
| Android 与 iOS | 不纳入 Snipaste 桌面全量验收；保留现有附件路径 |

错误状态至少覆盖：权限拒绝、快捷键占用、显示器变化、剪贴板写入失败、磁盘不足、历史文件丢失、窗口创建失败和无效会话。发生错误时说明失败动作并保留可恢复数据；不会以“已完成”代替失败。

## 实现边界

Rust 继续负责抓屏、系统窗口信息、全局快捷键、剪贴板、原生窗口和持久化；React 负责编辑交互和一致渲染。现有适配器继续隔离桌面与 Web。新增命令必须同步更新 main.rs、lib.rs、permissions 和 capability，保持旧消息与聊天附件协议兼容。

每个屏幕单独记录物理位置、物理尺寸、逻辑尺寸及比例。选区和标注存储使用原始图像坐标，显示变换不修改源数据。跨屏输出的像素密度策略须在多屏验证阶段固定，并记录对不同 DPI 图像的重采样方式；不能只使用主窗口的一个 scale factor。

贴图状态由单个 Option 改为按 ID 管理的集合；命令和事件携带目标 ID，避免不同贴图操作串图。编辑数据保留原图引用、选区、标注对象和历史版本。缓存、历史记录与用户另存文件分开管理；持久化只增加截图专用数据，不修改现有聊天表语义。

## 原型评审入口

打开 [文字与选区原型](../../ui-ref/xchat-desktop-prototype.html?review=capture&focus=text)。也可在原有桌面演示场景选择“XChat 截图与贴图 · 交互评审”，或点击聊天输入栏的截图按钮。原型沿用 XChat 绿色主动作和浅色面板；截图工具条以图标为主，辅助参数跟随当前工具展开。

建议依次评审以下流程：

1. 先单击示例文字修改，调整字体、字号与颜色，再提交、重新编辑和拖动；检查 T01 至 T10，尤其是位置是否跳动。
2. 切换“调整选区”，移动或缩放裁剪范围；检查 Enter 换行、框外点击、边框拖动和 Delete 删除；保存 PNG 对照。不同密度在开始截图前选择。
3. 开始新截图，悬停识别与手动框选；绘制形状、画笔、荧光笔、模糊、马赛克和橡皮擦，撤销、重做。
4. 产生多张贴图，分别移动、旋转、翻转、调透明度、缩略和隐藏；在管理面板恢复、分组、找回屏外图。
5. 试用穿透恢复、复制失败和权限拒绝演示；将截图加入模拟聊天草稿，确认不会直接发送。

原型使用内置演示桌面像素，不读取真实屏幕。PNG 下载由浏览器执行；复制到剪贴板使用浏览器能力并显示真实成功或失败，F3 读取演示剪贴板并新建图。控件识别、像素密度和窗口穿透为页面内模拟，没有实现原生多屏捕获。贴图与历史在本地原型存储中恢复，失败时保留当前会话并说明原因，不写入 XChat 数据库。
