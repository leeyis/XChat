## 范围与交付

原型入口必须为 `ui-ref/xchat-desktop-prototype.html`。提供任务状态与可恢复操作、设备/网络诊断、备份与恢复预检查、远程查看/独立控制授权/撤销与结束。所有业务数据均为演示，不操作真实设备或数据库。

生产前端/Rust/截图文件均不修改。依据 AGENTS.md：“Do not implement the UI change in the production application until the user has explicitly reviewed and approved the prototype.” 本轮交付是可评审方案，批准后再推进共享核心与双端实现。

## 步骤

1. 阅读现有原型和设计规范，确认导航、组件与可复用交互。
2. 比较入口组织方式，选择符合当前产品的一种；定义状态和反馈。
3. 在既有原型中实现完整点击路径，不只提供静态画面。
4. 浏览器验证正常/拒绝/失败/恢复/撤销状态，核对桌面和窄窗口布局。
5. 保存评审说明和真实验证证据，提交并提供可打开的预览链接。

## 评审入口

运行 `rtk proxy python -m http.server 18893 --bind 127.0.0.1 --directory ui-ref`，打开：

`http://127.0.0.1:18893/xchat-desktop-prototype.html?review=phase3`

顶部四个快捷入口对应四个模块；右侧场景菜单可切换异常。远程协助用“切到共享方视角／切到查看方视角”演示双方响应。重置按钮恢复本页的初始演示数据；退出评审返回原有原型。

可追加 `&p3=tasks`、`&p3=diagnostics`、`&p3=backup` 或 `&p3=remote` 直达对应模块。直接双击 HTML 也可使用原有评审场景选择框进入阶段三。

## 导航与设计取舍

任务中心是跨会话的日常操作，放在主轨道；诊断和备份为低频操作，复用设置导航；远程协助从单人会话标题栏进入。避免把所有内容埋进设置，也避免为四个功能各加一个主导航项。顶部评审栏是原型工具，不是生产界面的一部分。

保持当前中性色、绿色强调、线性图标和紧凑布局。用户在 2026-10-10 反馈任务图标后，将三行列表更换为任务夹板＋对勾。聊天、文件和截图交互沿用原型。新增资源仅在阶段三场景启用。

## 可评审流程与状态约束

| 模块 | 建议操作 | 要观察的行为 |
|---|---|---|
| 任务中心 | 筛选、搜索、打开群消息详情、批量取消 | 逐收件人展示；已送达项不重复处理；取消只停止后续发送 |
| 文件恢复 | 对“设计交付包.zip”重新选择源文件 | 不同内容阻止续传，相同内容从已确认部分继续 |
| 送达确认 | 对待确认消息继续确认；再取消 | 沿用原任务；取消后迟到回调不能把它改成完成 |
| 连接诊断 | 切换对象和场景，重新检查、展开详情、导出预览 | 区分发现、连通和身份；身份不符停止发送；默认隐藏地址，不导出正文 |
| 备份 | 选择附件；切换空间不足；更换位置；取消或完成 | 估算包含附件；完成并校验后才加入记录；取消不会留下完成条目 |
| 恢复 | 选择损坏备份或正常备份，查看合并预览 | 损坏时不能恢复；重复跳过、当前记录保留；偏好设置默认不覆盖 |
| 查看对方屏幕 | 请求查看，切到共享方拒绝或选择屏幕后同意 | 未同意前没有画面；只授予查看 |
| 邀请看我的屏幕 | 选择屏幕、发送邀请，切到查看方接受 | 对方接受前不共享；双方姓名和权限方向正确 |
| 控制 | 查看方申请控制，共享方拒绝或单独同意 | 只有明确允许后才出现控制状态；共享方可立即撤销 |
| 会话恢复 | 暂停、切屏、断线、锁屏、结束 | 暂停/切屏收回控制；断线/锁屏隐藏画面；重连重新同意，控制不自动恢复 |

远程示意桌面用 HTML 绘制，不采集真实屏幕。画质有自动、流畅、清晰三档；远程授权不包含剪贴板与文件共享。该原型先按 Windows 双方支持能力展示，其他平台以后依据实际能力显示入口。

## 与后续生产实现的衔接

1. 先把共享核心中的持久任务状态、执行租约、收件人结果和有限重试映射到任务中心，保持 desktop/web 一致。
2. 将已有网络健康和身份验证结果转为可操作的诊断步骤；导出保持脱敏，检查不自动修改防火墙。
3. 备份依赖一致快照、空间预检查和完整性校验；恢复需兼容性检查、保留恢复前副本、事务合并与失败回滚。历史任务不得因恢复而自动重发。
4. 远程先做查看的传输与资源预算验证，再加入会话绑定的控制授权、撤销和断线失效。未经用户批准的系统权限、平台入口和明显 UI 变化需先更新原型。

本轮没有对上述生产能力作实现或性能承诺，也没有启动真实备份、修改数据库、读取桌面或注入输入。当前截图功能不属于本阶段改造范围。
