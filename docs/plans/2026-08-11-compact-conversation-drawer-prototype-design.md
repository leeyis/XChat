# XChat 紧凑会话抽屉原型设计

## 目标

在 `ui-ref/xchat-desktop-prototype.html` 中重新设计群聊和单聊侧边抽屉，解决当前功能按钮纵向拉伸、按钮过宽、信息层级松散的问题。原型用于视觉评审，确认后再单独实现到正式客户端。

## 范围

- 只修改指定桌面原型文件，不修改 `frontend/` 或 Rust 后端。
- 同时覆盖群聊抽屉和单聊抽屉。
- 保留现有群成员、聊天记录、群公告、群聊设置、设备备注、清空记录、置顶会话和标记未读入口。
- 不改变已有弹窗内容、业务数据或后端行为。

## 已比较方案

### A. 内嵌分组列表

抽屉内左右留白，将操作放入圆角分组列表。每行固定 40px，以图标、标题、右侧数值或箭头表达操作。层级明确，同时避免通栏按钮显得过大。

### B. 通栏设置列表（最终采用）

操作直接铺满抽屉宽度，最接近传统微信设置页。通过固定 40px 行高和紧凑间距避免按钮拉伸。

### C. 折叠次要功能

只显示高频操作，其他操作收进“更多设置”。空间最省，但查看群公告和搜索聊天记录会增加一次点击。

## 布局

### 共用框架

- 抽屉宽度保持 240px，确保 IP 和 MAC 地址可完整显示。
- 身份和详情内容左右内缩 12px，设置列表铺满抽屉宽度。
- 顶部身份区使用 56px 头像，标题、状态间距控制在 4–8px。
- 内容区按自然高度排布，不使用弹性布局拉伸操作行。
- 底部固定 48px 高的状态操作栏，居中并排显示“置顶会话”和“标记未读”。

### 群聊抽屉

顺序如下：

1. 56px 群头像、群名称和成员数量。
2. 横向成员预览和添加成员入口。
3. 一个通栏设置列表，依次包含：
   - 查看群成员，右侧显示成员数量；
   - 查找聊天记录；
   - 发布群公告；
   - 群聊设置。
4. 底部状态操作栏。

### 单聊抽屉

顺序如下：

1. 56px 用户头像、显示名和在线状态。
2. 始终展开的紧凑设备信息，使用“左侧标签 + 右侧值”布局，包含主机名、当前地址、MAC 地址和发现方式；每行约 32px，IP 和 MAC 不省略。
3. 一个通栏设置列表，包含：
   - 修改设备备注；
   - 清空聊天记录。
4. 底部状态操作栏。

## 视觉规格

- 设置列表使用上下 1px 分隔线，无圆角、无阴影。
- 设置行固定 40px，高度不随抽屉剩余空间变化。
- 行内图标为 18px 线性图标，文字为 14px。
- 普通跳转操作右侧使用轻量箭头；信息行右侧显示当前值。
- 悬浮背景使用低对比中性色，按下状态略深。
- 键盘焦点使用主题绿色内描边。
- 清空聊天记录和解散群聊使用红色文字；不使用大面积红色背景。

## 原型结构

原型采用现有页面作为宿主，不新增路由。通过 `?variant=` 切换三个可比较方案：

- `A`：内嵌分组列表；
- `B`：最终采用的通栏设置列表，默认展示；
- `C`：折叠次要功能。

页面底部提供仅用于原型评审的浮动切换条，支持点击左右箭头和键盘左右方向键。输入框聚焦时不拦截方向键。切换结果写入 URL 参数，刷新后保持。

## 交互

- 群聊和单聊仍通过左侧会话列表切换，抽屉同步展示对应状态。
- 设置行继续调用原型中已有的成员管理、聊天记录、群公告、群聊设置、备注和确认弹窗。
- 底部两个状态按钮在原型内切换选中状态并显示反馈，不连接真实持久化。
- 危险操作继续经过确认弹窗。

## 验证

- 在 1440×900 和 1200×800 视口分别检查群聊、单聊两种抽屉。
- 确认所有设置行高度均为 40px，底部状态栏为 48px。
- 确认主机名、IP、MAC 和发现方式始终可见。
- 确认三种 `?variant=` 可通过切换条和键盘切换，刷新后保持当前方案。
- 检查浏览器控制台无新增错误，既有弹窗入口仍可点击。

## 非目标

- 不修改撤回、消息定位、群管理等业务逻辑。
- 不引入新的前端依赖或构建工具。
