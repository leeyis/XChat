# 阶段三生产实现

基线 `437bfcc`，用户已明确批准原型并要求完整实现。当前三份原型文档分别约定任务/诊断/备份、远程双向请求、远程语音/聊天语音；生产实现忠实沿用，不保留原型角色切换和演示场景工具。

## 实施顺序

1. 真实聊天语音：录制权限、1–60 秒、取消、待发送、稳定消息 ID、已有文件队列传输、接收播放、缺失恢复。录制取消/会话切换/卸载停止所有 track，60 秒只停止不自动发送。
2. 任务中心：持久消息/文件状态、逐收件人结果、取消、重试/继续确认、重选同一源文件与摘要验证。诊断：发现/连接/身份/资源的真实状态，脱敏导出。
3. 备份恢复：SQLite 一致快照，附件清单/摘要/空间检查，损坏与版本拒绝，事务合并且保留现有记录，恢复前副本；恢复历史消息不生成待发送任务。
4. 远程协助：内存会话注册与受控信令，两种请求、接收/拒绝/过期/取消；WebRTC 局域网屏幕和双向语音，真实能力探测，无公网中继。
5. 远程控制：会话绑定、明确授权、仅 pointer/key/wheel 白名单；共享方可随时撤销，暂停/切屏/断线/锁屏清空授权。平台能力按实际实现暴露。
6. 逐项端到端验收、desktop/web 检查、可用移动目标编译、生产 Tauri 冒烟与浏览器布局验收。重要功能验证后分批提交。

## 保持的约束

- 既有截图/编辑/贴图/快捷键源代码与资源保持原样；远程捕获独立实现，不改截图链路。
- 共享 Rust 核心承载持久行为与会话验证，Tauri 和 Web adapter 只做薄适配；用户明确无需兼容旧客户端。直接升级协议，保留本地现有数据。
- 不使用模拟数据冒充生产能力，未验证的真实多机/音频设备/平台在交付中明确列出。
- 使用隔离端口、临时数据库、合成测试音频与专用浏览器实例；不替换用户安装或操作日常数据库。
- 原有 analysis/ 不动；不推送。原型批准已具备，无需再次请求普通实现权限。
