## 验证范围与使用边界

Windows 桌面支持受控；浏览器共享为仅查看，也可以作为协助方控制已授权 Windows。使用可信局域网，不包含公网中继、无人值守控制或绕过系统权限。普通权限进程不能控制管理员窗口与安全桌面。

本轮为隔离实例自动化验证。浏览器设备源为明确标识的合成画面/麦克风，原生桌面帧只在内存验证；没有向用户日常应用注入测试键鼠。真实双机长时间联机、物理音频设备与回声、实际系统键鼠、物理锁屏/UAC 尚未实测，不作相关性能或兼容性保证。
