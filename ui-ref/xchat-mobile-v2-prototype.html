气泡统一成绿底黑字

按你的意见，两个主题都用 #9df29f 底 + #221c15 字，12.56:1，深浅色下都远超 WCAG AA。

原来的写法是 color: var(--fg)，深色下 --fg 翻成近白色，才掉到 1.09:1。现在把这两个值钉死成不随主题走的令牌，问题消失，气泡品牌感也保住了。

移动端屏蔽的功能

每一条都有代码依据，不是凭感觉砍的。

  • 输入区的截图按钮 — xchat.js:230 里 Android 的 capture 恒为 false（「桌面端三个平台都有原生抓屏后端；Android 仍然没有」）。之前它是个永远灰着的按钮，占着位置还让人以为坏了。直接移除，不置灰。
  • 整节「快捷键」设置 — 同一条依据，captureShortcut: false。手机没有全局快捷键这个概念，这项设置无从设置。
  • 下载目录 / 数据库路径的文件夹选择器 — commands.rs:2315 在 Android 下直接返回错误「当前平台不支持选择应用数据文件夹」。现在用户点一下只会拿到报错弹窗，比没有还糟。
  • 拖拽文件到输入区 — App.jsx:2059 起的 onDragEnter/onDragOver/onDrop 和 drag-active 遮罩。触摸屏没有文件拖拽，这段代码在手机上永远不会触发。
  • 消息右键菜单 — onContextMenu。触摸屏没有右键，改成长按，菜单项不变。
  • 悬停浮出的快捷操作条 — .message-quick-actions 靠 opacity:0 + :hover 显示。手机上永远不显示，收进长按菜单。
  • 「打开所在目录」 — revealFile 在 Android 恒为 false。保留「打开」（openOutgoingFile 走 tauri，可用）。
  • 逐网卡发现列表 + TUN 风险提示 — 手机通常只有一两个网络接口，代理 TUN 是桌面概念。收进「高级」，且只在接口数 > 1 时出现。

顺手改掉的交互

  • 回车不再发送 — 手机上回车键是唯一的换行方式，抢来发送就没法换行了。改成回车换行、点按钮发送。这也是微信的行为。
  • 未读角标挪到头像右上角，右侧只留时间。
  • 列表页搜索收进图标，点了才展开。
  • 设置改成「我的」：身份卡 + 分组列表，七个分节收成五个入口。

safe-area

底部 Tab 栏和输入区必须避开手势条，否则最后一行按钮会被压住。真实做法：

flex-basis: calc(54px + env(safe-area-inset-bottom, 0px))
padding-bottom: env(safe-area-inset-bottom, 0px)

另外 index.html 的 viewport 要补 viewport-fit=cover，否则 env() 恒为 0。原型里那 22px 手势条是示意。

两个 ➕ 的流程

聊天 ➕ → 新建群聊：群名称 + 成员多选，至少 2 位才能点「完成」，对应 GroupModal 里 members.length < 2 的校验。

主机 ➕ → 添加设备：填地址 → 测试连接 → 保存。必须先测通，对应 canSaveVerifiedEndpoint() —— 这一步会核对对方的设备身份，防止地址写错连到别的机器。

隐身对设计的影响

代码里已经有 discovery_source === "manual" 和 labels.manual（「手动添加」），也有现成的文案 discoveryAllOff：「自动发现已暂停，已添加的设备仍可通信，新设备需手动添加」。所以底子是有的。

隐身一旦上线，「添加设备」就从锦上添花变成唯一入口。由此带来三件事：

  • 主机列表要标出「手动添加」，让人分得清哪些是扫到的、哪些是自己填地址加的
  • 新建群聊的成员列表会变短，因为隐身的人不出现。所以群聊页里也放了「手动添加设备地址」的入口，加完自动回来
  • 空状态要能救场：主机页一个设备都没扫到时，不能只说「暂无设备」，要直接给「手动添加地址」的按钮和一句解释

还需要你确认的

  • 隐身是单向还是双向？ 我按「我不广播自己，别人看不到我」设计的。如果还要支持「我不想看到某个设备」，那是另一种机制（本地黑名单），别混成一个开关。
  • 隐身设备之间的发现怎么走？ 双方都隐身、又都手动加了对方，能互通吗？现有文案说「已添加的设备仍可通信」，但那说的是单方添加。
  • 「撤回」在长按菜单里是空壳——代码里只有 status === "recalled" 的过滤，没有发起撤回的动作。后端到底有没有这个能力？
  • 通知设置现在只有一个开关，Android 上系统未授权时它不起作用，要不要加授权状态和跳转。
