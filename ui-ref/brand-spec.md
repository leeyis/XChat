# XChat 视觉系统

XChat 使用冷静的中性桌面界面承载高密度通讯信息，以参照图取样的微信绿强调关键动作、选中态与传输进度；浅色与深色主题保持完全相同的信息层级。

## 六个核心令牌

```css
/* 浅色 */
--bg: oklch(0.975 0.004 75);
--surface: oklch(1 0 0);
--fg: oklch(0.23 0.015 70);
--muted: oklch(0.55 0.012 70);
--border: oklch(0.89 0.008 70);
--accent: oklch(0.659 0.145 159.36); /* #18AC71 */

/* 深色：--accent 保持不变 */
--bg: oklch(0.17 0.01 70);
--surface: oklch(0.22 0.012 70);
--fg: oklch(0.93 0.005 75);
--muted: oklch(0.69 0.01 75);
--border: oklch(0.32 0.012 70);
--accent: oklch(0.659 0.145 159.36); /* #18AC71 */
```

## 字体

- 界面与正文：`-apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`
- 显示标题：`"Songti SC", STSong, SimSun, serif`
- 地址、速度、大小和时间：`ui-monospace, "SFMono-Regular", Consolas, monospace`

## 姿态规则

- 四栏布局只固定导航、列表和信息面板宽度，消息区独占伸缩空间。
- 主导航的当前功能仅改变图标自身颜色，不使用底色或侧边装饰条，以免与列表整行选中态争抢层级。
- 浅色主题的主导航使用微信式冷浅灰底；深色主题维持深色导航，两者都以绿色图标表示当前功能。
- 消息输入区采用完整边框容器：文本区在上，表情、截屏、文件工具栏固定在底部，发送动作位于右下。
- 微信绿仅用于当前选择、主动作、发送气泡和活动进度，不作为大面积背景装饰。
- 设备身份以 MAC 地址为稳定主键，默认同时显示主机名、IP 与 MAC；用户备注始终绑定 MAC。
- 设备头像支持内置卡通形象与确定性色块；在线状态、IP 与发现方式共同构成设备身份。
- 文件卡片必须同时显示阶段、进度、速度和可执行动作，绝不把状态压缩为一行小字。
- AI 思考、工具调用和模型选择器共享同一套可折叠卡片语言。
