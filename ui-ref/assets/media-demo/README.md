# Media review fixtures

These small, original fixtures belong only to the UI prototype. No external media is fetched during review.

- `preview-chime.wav`: 12 seconds of quiet synthesized notes.
- `network-preview.mp4`: 8 seconds of an animated local network diagram, H.264 video with AAC audio.
- `chat-motion.gif`: a looping chat illustration.
- `*-poster.png`: still frames used before video playback or while the animation is paused.

Regenerate from the repository root with `rtk proxy python ui-ref/assets/media-demo/generate_fixtures.py`. Pillow and FFmpeg are generation tools, not production dependencies.
